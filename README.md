# Sorting and Searching Algorithms

Sorting and searching algorithms implemented from scratch in Python, without library shortcuts.

## Contents
| File | Algorithm | Complexity |
|---|---|---|
| `ordenamiento-de-burbuja.py` | Bubble sort | O(n²) |
| `ordenamiento-por-insercion.py` | Insertion sort | O(n²), O(n) best case |
| `busqueda-binaria.py` | Binary search | O(log n) |
| `estructura-secuencial.py` | Sequential structure | O(n) |
